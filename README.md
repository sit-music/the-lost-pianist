# 末法时代的钢琴家

> **The Lost Pianist** · 一部关于中国钢琴生态的复调非虚构开源图书

钢琴在中国经历了四十年狂飙，正在经历一场结构性退潮。这不是"钢琴不行了"的唱衰，而是追问——**当考级、焦虑、产能、信仰同时退场，钢琴还剩下什么？**

本书以约 30 万字的深度，书写中国钢琴的业余培训、专业教育、产销研、爱好者社区、发展与反思，以及 AI 时代的洞察。采用**复调非虚构**：客观报道（数据 / 访谈 / 机制）与"我"的亲历线索交织——一个学过琴、放弃过、又在末法时代回到琴凳的人。

> **末法是结构判断，不是情绪判决。** 退潮之中有逆势：电钢在增长、龙头 2026 上半年营收回暖、龙年出生人口回升。本书同时解释"什么在退"与"什么在进"。
