## 一、数据口径纪律（本书的严谨底线）

行业数据混乱是本书必须正面处理的问题，而非回避：

- **钢琴产销量有三套互相矛盾的口径**，不可混用：
  - 中国乐器协会《2024 产业白皮书》**销量**口径
  - 理事长王世成 **产量**口径
  - 雅马哈西村淳 **销量**口径
  - 三者峰值年份不同（2018/2019/2021）、量级不同。引用时必须标明"口径 + 来源 + 年份"。
- **"琴童总数"无权威普查**："3000 万""4000 万""6000 万"均为转述或估算。本书改用**可核查的硬代理指标**（如上海音协钢琴考级人数降幅）来刻画趋势，并明确标注估算性质。
- **自媒体数字一律降级**："7000 家琴行倒闭""校考 300→38 所""报名 -20 万""涉案超 6 亿"等仅见于自媒体，列为待核实，未获一手来源前不进正文。
- **可信度三级**：高（官方/年报/权威媒体）· 中（行业媒体/二手转述）· 低（自媒体/估算）。正文论断原则上只用"高/中"，且"中"需交叉验证。
- **M1 必须回溯一手来源**：上市公司年报原文、统计局公报、协会白皮书、教育部政策原文。聚合页（新浪/同花顺/企查查）只作线索，不作终证。

## 二、理论透镜（六条解释线 → 可操作研究问题）

| 透镜 | 核心问题 | 关键证据 |
|---|---|---|
| 人口重力 | 生源萎缩是否结构性、不可逆？领先指标几年？ | 出生人口序列、琴童年龄分布、考级人数 |
| 政策周期 | 每道政策如何重塑激励？谁受益谁出局？ | 双减、艺考改革、非学科监管、美育中考原文 |
| 产业周期 | 产能如何过剩、出清、转型？ | 珠江/海伦财报、存货减值、电钢销量 |
| 文化资本/阶层 | 钢琴作为身份符号如何兴起与祛魅？ | 家长访谈、消费话语、阶层退出案例 |
| 技术替代 | 电钢/AI/流媒体替代的边界在哪？ | 电钢增长、AI 陪练技术、流媒体古典数据 |
| 具身认知 | 演奏为何难以被 AI 替代？ | 演奏身体性、现场性、教育性文献与访谈 |

## 三、访谈矩阵（12 类角色）

| 角色 | 核心问题 | 目标样本 |
|---|---|---|
| 琴行老板（含倒闭/转型） | 库存、现金流、三次转型、关店决策 | 4–6 |
| 钢琴教师（科班/转行/销售型） | 课时费、获客、回扣、转行去向 | 6–8 |
| 琴童家长（坚持/放弃） | 投入产出、亲子冲突、退出决策 | 6–8 |
| 音乐学院师生 | 养成成本、就业出口、艺考改革体感 | 4–6 |
| 制琴师/厂方 | 产能、库存、电钢转型、技术 | 2–4 |
| 二手琴商/翻新作坊 | 进口产业链、价格踩踏、信任 | 2–3 |
| 调律师 | 行业老龄化、AI 调律、收入 | 2–3 |
| 成人/银发学习者 | 补偿心理、自学路径、社区 | 4–6 |
| 社区版主/UP 主 | 去机构化学习、内容生态、变现 | 3–4 |
| 陪练平台前员工 | 资本史、暴雷内幕、AI 转型 | 2–3 |
| 老一辈钢琴家/教育者 | 口述史抢救、学派记忆 | 2–3（优先） |
| 政策/协会研究者 | 制度设计逻辑、数据口径 | 2–3 |

> 伦理：匿名化处理、知情同意、敏感内容（回扣/暴雷/欠薪）脱敏；通过 repo `CONTRIBUTING.md` 公开征集。

## 五、待核实清单（M1 优先攻坚）

1. 钢琴产销量三套口径的**原始白皮书/访谈全文**，统一为可对照表
2. "7000 家琴行倒闭"是否有工商/协会一手数据
3. 校考院校数"300 余→38 所"、艺考报名"-20 万"的官方出处
4. 小叶子工商口径（员工/营收/融资轮次）与 Find 智慧钢琴 2023 后近况
5. 日本钢琴市场**官方逐年序列**（目前仅访谈与百科零散数据）
6. "3000 万琴童"的原始普查或协会方法论
7. 珠江 2026H1 回暖、海伦电钢 +49.57% 的**半年报原文**核实
8. 出生人口 2016 口径（1786 万 vs 七普修订 ≈1883 万）统一

## 六、反向证据清单（强制处理，避免确认偏误）

- 珠江钢琴 2026H1 营收 +10.24%、亏损收窄 8.49%
- 海伦数码钢琴 2026H1 销量 +49.57%
- 2024 出生人口龙年回升 +52 万（非连续下滑）
- 双减后艺术+体育培训企业一度新增 3.3 万家、+99%
- 全球录制音乐 2025 连续第 11 年增长、中国成第四大市场（+20.1%）
- 在线音乐教育市场 2026→2031 CAGR 15.23%

> 本书论点必须能解释这些逆势：**退的是"真钢+功利培训"的旧生态，进的是"电钢+爱好+AI 工具"的新生态。**

## 八、M1 调研工作流

1. 回溯一手来源，补全 `数据/数据锚点.md` → 形成数据字典
2. 编制行业年表（1980–2026）与政策年表
3. 建立来源存档（网页/财报快照，防链接失效）
4. 启动访谈征集（CONTRIBUTING + Issue 模板），优先老一辈口述史
5. 交叉验证"中"级数据，剔除"低"级噪音
6. 产出 M1 调研简报，评审后进入 M2 样章
