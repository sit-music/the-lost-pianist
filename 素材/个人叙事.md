# 个人叙事线索 · "我"（待作者真实素材）

> 本书采用复调非虚构，"我"的亲历线索与客观报道交织。**本文件是引导清单，不是成稿。**
> ⚠️ 硬约束：所有"我"的经历必须基于真实经验，**不虚构**。请作者据实填写，可匿名化他人。
> 填写后，M2 样章据此定"我"的声音与身份。

## 一、身份锚定（先确定"我"是谁）

- 你与钢琴的真实关系是？（可多选）
  - [ ] 琴童本人（学过 ___ 年，___ 岁开始，___ 岁放弃/坚持）
  - [ ] 琴童家长
  - [ ] 钢琴教师 / 从业者
  - [ ] 成人重返学习者
  - [ ] 旁观者 / 爱好者
- 你现在还弹吗？多久弹一次？弹什么？
- 你希望"我"在书中以什么身份出现？（真名 / 笔名 / 匿名）

## 二、关键场景（每部需要一个真实锚点）

请尽量回忆**具体的时间、地点、感官细节**（声音、光线、气味、触感）：

| 对应 | 引导问题 |
|---|---|
| 序章 | 你最近一次与一台钢琴相遇/重遇，是什么场景？那一刻你在想什么？ |

## 三、情感锚点

- 学琴留给你的核心情绪是什么？（羞耻 / 焦虑 / 治愈 / 遗憾 / 和解 / 热爱……）

- 有没有一首曲子，对你有特殊意义？为什么？

## 四、边界与伦理

- 哪些内容可以公开？哪些需要匿名化或省略？
- 涉及他人（老师/家长/机构）的负面内容，是否已脱敏？
- 是否同意以录音口述 + 我们整理的方式提供？
