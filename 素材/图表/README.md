## 全局制图纪律（验收自查记录）

1. **数值回链**：每图每个数值均取自上表所列锚点节号原文；无任何锚点外数字——百分比与差值亦用锚点原文表述（如「+52 万」「-5.7%」「占全球约 75%」「增 97 万」），未自行计算衍生值。
2. **散点不插值**：日本产量只有 7 个散点年（1995/2000/2005/2010/2011/2012/2013），不连成连续曲线；断点注记（「前年又は平成12・17年とは接続しない」、2008/2010 口径变更、2010/2011 不接续）以轴上 ∥ 记号＋脚注双重呈现。中国产量、出生人口、考级序列的缺年处一律断线＋∥，不填充、不插值。
3. **口径不可比标注**：国际对照三面板独立坐标轴、独立单位（万台/万架/兆韩元），顶部横幅警示「不可直接对齐」；韩国需求端 vs 日中供给端的语法差异在面板方法行与底部脚注两处标注，并注明 §13.2 方向裁决（韩国列不支持与日中「供给坍缩」同构）。
4. **坐标轴从 0 起**：全部图表 y 轴自 0 起，无截断（故产量图无需另注截断说明）。
5. **风格**：白底、黑灰线条、无装饰、中文标签；900×500；正文/刻度 ≥11.5px、关键标注加粗，高对比适配年长读者。
6. **弃用项不出现**：锚点 ❌ 清单（协会《2024 产业白皮书》35.6 万→12.8 万序列等）未在任何图中出现。
7. **排版安全区（2026-11-25 打回修复后新增）**：QuickLook 缩略渲染对 900 宽 viewBox 按 ≈1.19 倍绘制并在图像 900px 处裁切——**可见区只有 viewBox x ≲ 756**。故全部图文（含文本右缘、最末 x 刻度标签）控制在 x ≤ 750 安全区内：底部脚注一律 tspan 分行（每行 ≤ ~52 个全角字符）；右侧点标签一律 `text-anchor="end"` 置于点左侧/上方；验收以 QuickLook 渲染 PNG 逐边目检为准（左/右/上/下四边末字符完整）。
