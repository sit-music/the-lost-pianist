## 一、CEPS（中国教育追踪调查）数据申请评估

### 1. 平台与申请入口现状（一手实测）

- CEPS 官网 `http://ceps.ruc.edu.cn/`（HTTP 200，curl 直取成功）可正常访问，由中国人民大学中国调查与数据中心（NSRC）运营。站内栏目：项目介绍 / 项目文档（抽样设计、调查手册、调查问卷、技术报告）/ 数据成果 / 研究成果 / 联系我们。可信度：高（官方一手）。
- **数据发布已迁移至新平台**：《中国人民大学社会科学数据资源平台（CSSD）正式上线公告》`http://ceps.ruc.edu.cn/info/1006/1058.htm`（HTTP 200）载明：
  - CSSD（`https://cssd.ruc.edu.cn/`）于 **2026-07-13 正式上线**，由人大中国调查与数据中心打造；
  - 平台整合 8 个核心调查数据库，其中 **CEPS 为"已发布数据集"——"已公开发布 3 期数据"**（另三个已发布为 CGSS、CLASS、中国雇主—雇员匹配数据跟踪调查）；
  - **申请机制原文**："用户实名认证并签署数据使用协议后，公开数据可一键下载，受限数据可在线申请审批获取"；
  - 平台提供数据集/文件/变量多维度检索，支持标准引用格式一键导出。可信度：高（官方一手公告原文）。
- 旧数据平台 `cnsda.ruc.edu.cn`（官网"数据成果/调查数据"仍指向该站）**DNS 已无法解析**（2026-11-25 本地 dig/nslookup 实测无记录；curl exit 6）；`nsrc.ruc.edu.cn` 解析到 webvpn CNAME（106.120.213.214），校外 curl 未取到页面。可信度：中高（实测，但属访问侧现象）。
- `https://cssd.ruc.edu.cn/` 可达但对 curl 返回 React SPA 壳页（878 字节，前端资源 `/assets/index.C2VHcknU.js`），**申请/审核细则页为客户端渲染，curl 无法直取**，注册与申请须浏览器操作。可信度：高（实测）。

### 4. 申请材料草稿（按 CSSD"在线申请审批"通用格式拟制；官网项目书模板不可取——SPA，故按通用格式）

> **数据使用申请（草稿 v0.1，待 CSSD 注册后按站内表单字段调整）**
>
> 1. 申请人：〔姓名/单位/身份类别——按平台实名认证字段填写〕
> 2. 研究主题：非虚构图书《末法时代的钢琴家》所附教育公平研究——课外艺术类参与的城乡与流动差异。
> 3. 研究设计简述：利用 CEPS 全国代表性两阶段分层随机抽样学生及其家长数据，比较城镇户籍与农村户籍、随迁与非随迁初中生在课外班/课外活动（重点：艺术/音乐类）参与率、类型与强度上的差异；以描述统计与回归分析（控制家庭社会经济地位、学校固定效应）呈现教育机会的城乡/流动分层；成果为图书公开出版物中的引用性论证，非商业数据库开发。
> 4. 所需数据：CEPS 已公开发布各期（基线及追访）学生问卷、家长问卷合并数据。
> 5. 所需变量清单：①学生课外活动/课外班参与（含类型：艺术/音乐类——条目名以问卷 PDF 与 CSSD 变量检索为准）；②学生户籍性质（农业/非农业）；③流动/随迁身份（是否本地户籍、出生地/来本地时间）；④学校所在地城乡属性（县/区层级）；⑤家庭社会经济地位控制变量（父母教育/职业/家庭藏书量）。②③④⑤为 CEPS 公开发布版本的标准配置项。
> 6. 数据使用承诺：仅用于本研究；所有结果以汇总统计形式呈现，不识别、不披露任何个人、家庭或学校可辨识信息；不将原始数据转让、转售或再分发给未授权第三方；成果引用规范格式："中国教育追踪调查（CEPS），中国人民大学中国调查与数据中心（中国调查与数据中心 CSSD 平台）"，并按平台提供的标准引用格式导出引用；接受数据中心的合规监督。
